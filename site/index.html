Instalar en Windows

Necesitas Python 3.10 o superior. El asistente se abre en tu navegador, detecta tu hardware y te recomienda modelos, pero no descarga nada sin preguntarte.

  1. Descarga el código

    Clona el repositorio o descarga el ZIP.

    git clone https://github.com/LuisLeon1705/Clay-Myrrh.git

  2. Ejecuta el instalador

    instalar-clay-myrrh.bat comprueba Python y las librerías, crea los accesos directos y abre el asistente con la guía y la comparativa.

  3. Instala el motor

    El asistente te da el comando exacto según tu GPU. Con AMD o Intel, llama-cpp-python se compila con Vulkan; si no quieres compilar nada, usa Ollama.

  4. A trabajar

    Abre el acceso directo Clay-Myrrh o, desde una terminal:

    clay-myrrh                              # chat
clay-myrrh -d C:\proyectos\mi-web       # trabajar sobre una carpeta
clay-myrrh --grafo C:\proyectos\mi-web  # red del proyecto en Clay-Myrrh.md

Comandos principales

Escribe / en el chat para ver el menú completo, con descripciones y autocompletado.

/mem · /doctorestimar VRAM y RAM antes de cargar y diagnosticar la instalación

¿Para qué sirve una IA local?

Funciona en cualquier lugar, aunque no en cualquier equipo. Sirve para lo que no quieres enviar a la nube, para cuando no tienes conexión y para trabajar sin límites de uso.

Privacidad

Documentos, contratos, código de trabajo o fotos personales se quedan en tu disco.

Sin conexión

En un avión, en el campo o con mala señal: el modelo vive en tu equipo.

Sin cuotas

No hay mensajes contados ni cambios de plan: siempre el mismo modelo, todo el tiempo que quieras.

Con límites honestos

Un modelo local es más pequeño que los de la nube. El asistente te dice qué esperar de tu hardware.
