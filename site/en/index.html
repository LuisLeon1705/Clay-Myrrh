Everything you expect from a coding assistant, on your machine

Clay-Myrrh loads the model on your GPU (or in RAM if it doesn't fit), works out how much memory it needs before loading it, and tells you what to do when something goes wrong.

🔒

Fully local

Works offline. Your files, photos and conversations never leave your computer.

🗂️

Project mode

The model reads, searches, creates and edits the files in a folder with small edits. Every change keeps a backup and can be undone with /deshacer.

🕸️

Project map

/grafo maps your code without using the model: what each file uses, its routes, views and tables. It also warns you about pieces that don't fit.

👁️

Images and PDFs

Reads photos, screenshots and PDFs, scanned ones included. A vision model acts as a "reader" for any text model.

🔁

Automatic relay

Long answers continue on their own without re-reading what was already written, and the parts are joined at the end.

⛓️

Prompt chains

Chain steps with /cadena and leave it working. When it finishes, you get a report of every step.

🧩

57 web components

Full pages with very few tokens: the model writes tags and the program generates tested HTML, CSS and JavaScript.

🧭

Setup assistant

Detects your GPU (NVIDIA, AMD or Intel), recommends models for your hardware and compares local AI with Claude, Gemini and Codex.

Fewer tokens, fewer mistakes

Instead of reading everything, the model gets a map of the project: one line per file with its connections. It is stored in Clay-Myrrh.md, next to your instructions, like a CLAUDE.md or a GEMINI.md, and it updates itself.

Install on Windows

You need Python 3.10 or later. The assistant opens in your browser, detects your hardware and recommends models, but it never downloads anything without asking.

  1. Get the code

    Clone the repository or download the ZIP.

    git clone https://github.com/LuisLeon1705/Clay-Myrrh.git

  2. Run the installer

    instalar-clay-myrrh.bat checks Python and the libraries, creates the shortcuts and opens the assistant with the guide and the comparison.

  3. Install the engine

    The assistant gives you the exact command for your GPU. With AMD or Intel, llama-cpp-python is built with Vulkan; if you'd rather not build anything, use Ollama.

  4. Get to work

    Open the Clay-Myrrh shortcut or, from a terminal:

    clay-myrrh                              # chat
clay-myrrh -d C:\projects\my-site       # work on a folder
clay-myrrh --grafo C:\projects\my-site  # project map in Clay-Myrrh.md

Main commands

Type / in the chat to see the full menu, with descriptions and autocomplete. Commands keep their Spanish names.

CommandWhat it does
/modelchoose a model, with its size, whether it has vision and the memory it needs
/proyecto <folder>work on a folder: the model edits its files
/grafo [ver|avisos]project map and automatic checks
/cambios · /deshacersee and undo what the model changed
/cadena <file>run several prompts in a row, with a report
/zerobuild a website from scratch with a questionnaire and guided tasks
/compactsummarise the conversation to free up context
/mem · /doctorestimate VRAM and RAM before loading, and diagnose the installation

What is a local AI good for?

It works anywhere, though not on any hardware. It's for what you don't want to send to the cloud, for when you have no connection, and for working without usage limits.

Privacy

Documents, contracts, work code or personal photos stay on your disk.

Offline

On a plane, in the countryside or with a bad signal: the model lives on your computer.

No quotas

No message limits and no plan changes: always the same model, for as long as you want.

Honest limits

A local model is smaller than cloud ones. The assistant tells you what to expect from your hardware.
